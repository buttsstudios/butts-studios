About

Tiffany is a central monitoring platform for research infrastructure. It ingests metrics over a binary TCP protobuf stream, as well as length-prefixed JSON and StatsD over UDP, and shows them in live dashboards with drill-down views.

Storage is split by workload: PostgreSQL for transactional data, TimescaleDB for time series with continuous aggregation, and Redis for caching and sessions. Tiffany reports its own health through the same pipeline it uses for every other service.

A REST API with OpenAPI documentation, a CLI for operations tasks, an operator console for entitlements and LLM cost tracking, and an autonomous missions engine for routine development work complete the platform. It is offered under a one-time enterprise license with self-hosted, on-premise and hybrid deployment.
