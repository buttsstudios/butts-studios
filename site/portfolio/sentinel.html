About

Sentinel scans codebases for integrity issues: corruption, typo-class defects, copy drift, broken references and configuration inconsistencies across code, documentation and config files.

It runs quick, deep, ecosystem and CI/CD scan modes against a built-in pattern library, classifies each finding by severity, and opens guided repair sessions to apply fixes. Git history forensics help trace when an issue entered the codebase and how far it spread.

The same engine powers a CLI for CI and pre-commit hooks, a desktop app and a web dashboard, so findings stay consistent across all three.
